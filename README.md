# sanjeevani
Sanjeevani is a smart ambulance routing and dispatch mobile application with three interfaces: User, Hospital, and Ambulance Driver, designed to streamline emergency ambulance requests, dispatch coordination, and communication between patients, hospitals, and ambulance drivers.
A SMART AMBULANCE DISPATCH SYSTEM by which we can minimize the emergency response time and
can also track the ambulance.
It uses GOOGLE MAPS API, GEOCODING API to track the emergency spot, ambulance location, and
DIRECTIONS API to get the shortest path to reach the spot.
Using a LINKED LIST QUEUE the incoming emergency calls are processed sequentially, if there are no active
ambulances.

designing, logical thinking, and improved problem-solving skills.
